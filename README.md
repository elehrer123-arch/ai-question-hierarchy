# The Big Questions About AI

A navigable map of the landscape of thought around AI: 5 sections, 25 subsections,
125 open questions — each with a short framing of the live debate and curated links
to quality external sources (282 in total, including notable X posts by AI thinkers).
The ten load-bearing cruxes are marked ✱ on the questions that carry them.

The whole site is a single self-contained `index.html` (no build step, no dependencies).
Edit the JSON data embedded at the bottom of the file to add questions or sources —
pushes to `main` redeploy automatically via GitHub Actions.

Assembled July 2026.
