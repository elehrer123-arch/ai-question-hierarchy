# The Big Questions About AI

A navigable map of the landscape of thought around AI: 5 sections, 26 subsections,
124 open questions — each with a short framing of the live debate and curated links
to quality external sources (285 source links in total, including notable X posts by AI thinkers).
The ten load-bearing cruxes are marked ✱ on the questions that carry them.

The whole site is a single self-contained, statically-rendered `index.html`
(no build step, no dependencies, fully readable without JavaScript).
Pushes to `main` redeploy automatically via GitHub Actions.

Updated August 2026.
