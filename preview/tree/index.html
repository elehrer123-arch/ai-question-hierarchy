Four ways to draw the tree

Same 127 questions, same hierarchy, four very different embodiments (plus the first attempt for reference). Every node in every version opens its page in the browse view.

Radial — one circle, everything on screen at once; the strongest "poster" of the whole. Orchard — five top-down trees in a row; genealogical shape, one screenful. Regions — containment instead of lines; sections as territories, questions as places. Broadsheet — pure typography, no lines or boxes; the hero idiom at full-map scale. Elbow (v0) — the first attempt, kept for comparison.
