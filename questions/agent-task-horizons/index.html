Task horizon

How quickly will the length of tasks agents can complete reliably grow — from minutes to days, months, or entire organizational projects?

METR's 2025 measurement found the length of software tasks agents complete at 50% reliability doubling roughly every seven months, with faster doubling among recent models. Extrapolating that curve is a key input to short-timeline forecasts.

What changed
January–August 2026 · swept August 3, 2026 · editorial review pending
01

The measurement fight sharpened in both directions: a joint Epoch–METR benchmark shows the best model completing 56% of weeks-long software rebuilds, while Cursor's analysis finds most headline resolutions retrieved fixes rather than derived them. The horizon curve still doubles roughly every 3.5 months; what it measures is the open question. METR's own re-measurement (Time Horizon 1.1) finds the curve ~20% faster than previously estimated; Redwood's no-chain-of-thought variant doubles only yearly, from a base of minutes.Evidence: 1234

Expenditure Horizon: Measuring Optimization Ability
We define an agent's 'expenditure horizon' over an optimization problem as the dollar value at which the improvement to the goal metric is equal to the improvement by a human with the same budget.

A dollar-denominated complement to time horizon; finds current agents add little value on an open-ended AI R&D optimization task.
